# Sessao 10/08/2026 - WeParty Automation

## Objetivo
Criar cenario de cadastro com sucesso no projeto weparty-automation utilizando o email `user_teste_weparty_XXX@sharklasers.com`.

---

## O que foi feito

### 1. Instalacao do projeto
- `npm install` - 168 pacotes instalados
- `npx cypress install` - Cypress 15.20.0
- Credenciais copiadas: `credentials.example.json` -> `credentials.json`

### 2. Configuracao das credenciais
Arquivo: `cypress/fixtures/credentials.json`
```json
{
  "email": "pedrolopeshls@gmail.com",
  "password": "Teste12345@",
  "signup": {
    "name": "Test User WeParty",
    "password": "Teste@12345",
    "email_domain": "sharklasers.com"
  }
}
```
O email de cadastro e gerado dinamicamente com `Date.now()` pra nunca repetir:
`user_teste_weparty_<timestamp>@sharklasers.com`

### 3. Comandos customizados
Arquivo: `cypress/support/commands.js`
- `cy.login(email, password)` - comando de login (ja existia)

### 4. Teste de cadastro
Arquivo: `cypress/e2e/signup.cy.js`

**Fluxo do teste:**
1. Visita `/public/Signup`
2. Preenche: nome, email, senha, confirmar senha
3. Aceita termos
4. Clica "Concluir cadastro"
5. Aguarda redirecionamento para `/public/ConfirmEmail`
6. Abre sharklasers.com inbox no navegador para buscar o PIN
7. Faz polling (reload a cada 5s, max 30 tentativas) ate encontrar email do WeParty com PIN
8. Extrai o PIN (6 digitos) e salva em `Cypress.env('VERIFICATION_PIN')`
9. Volta para `/public/ConfirmEmail`
10. Preenche os 6 inputs `.pin-input` com o PIN
11. Aguarda redirecionamento para `/public/Interest`
12. Clica "Pular esta etapa por enquanto"
13. Aguarda `/public/AddFriends`
14. Clica "Pular esta etapa por enquanto"
15. Aguarda `/public/Congratulations`
16. Clica "Continuar"
17. Verifica redirecionamento para `/private/feed`

### 5. Configuracao do Cypress
Arquivo: `cypress.config.js`
- `baseUrl: 'https://www.wepartyapp.com'`
- `chromeWebSecurity: false` (permite navegacao cross-domain)
- Sem `cy.origin()` (deu erro de HTTPS/HTTP no sharklasers)

---

## Problemas encontrados e solucoes

### Problema 1: API do Guerrilla Mail nao funcionou
- `api.guerrillamail.com/ajax.php` - tentativas com `cy.request()` e `cy.task()` falharam
- **Solucao:** Navegar diretamente para `https://www.sharklasers.com/inbox/<emailUser>` no proprio navegador e fazer polling visual

### Problema 2: `cy.origin()` quebrou
- Erro: "failed to create a spec bridge to communicate with the specified origin"
- Motivo: sharklasers.com tem frames HTTP misturados com HTTPS
- **Solucao:** Usar `cy.visit()` direto com `chromeWebSecurity: false` ao inves de `cy.origin()`

### Problema 3: Email ja cadastrado
- **Solucao:** Gerar email unico com `Date.now()` como sufixo

## Pontos de atencao para amanha

1. **Teste nao foi concluido** - o cadastro e o redirecionamento para ConfirmEmail funcionam, mas a parte do sharklasers/polling de PIN precisa ser validada

2. **Possiveis ajustes no polling:**
   - O seletor do PIN pode precisar de ajuste (regex `/\b(\d{6})\b/` procura 6 digitos no texto da pagina)
   - Se o sharklasers nao exibir o email imediatamente, aumentar `maxPollAttempts` (linha ~47 do signup.cy.js)
   - O PIN pode vir em formato HTML, entao usar `.text()` no body deve funcionar

3. **Para rodar o teste com navegador visivel:**
   ```bash
   npx cypress run --spec "cypress/e2e/signup.cy.js" --headed --no-exit
   ```

4. **Fluxo alternativo se o polling falhar:**
   - Abrir manualmente `https://www.sharklasers.com/inbox/` 
   - Digitar o email alias gerado
   - Pegar o PIN manualmente
   - Voltar pro ConfirmEmail e digitar
